# Every file of tests/ that is not a test run by a workflow of .github/workflows is listed here with its kind and the reason
# (tests/ci-workflow-test.py fails for any other). A line: <path> | <kind> | <reason>.
# kind: helper = not a test (a library, a fake, a server or a tool that tests use); manual = a test or a measurement that needs
# what the CI does not have (a virtual machine, a desktop session, a real app) and is run by hand. The reason of a manual one says when to run it.
tests/isolation.py | helper | the rules for isolated homes, imported by the tests
tests/incremental.py | helper | the packages and the Range server that the tests of the store build on (also a test with its own arguments)
tests/range_server.py | helper | an HTTP server with Range support, started by the tests of update
tests/domain_server.py | helper | an HTTPS server that answers as the domain of an author, started by domain_confirm.py
tests/dbus_lab.py | helper | the private bus, portals and fake backends of dbus_filter.py and privbus.py
tests/dbus_fake_backend.py | helper | a fake portal backend for dbus_filter.py
tests/fake_native.py | helper | a fake native application on the session bus for dbus_filter.py
tests/fake_portal_files.py | helper | a fake file-chooser portal for gtk_filechooser.py
tests/fuse_server.py | helper | a small FUSE server that stands for gvfsd-fuse, started by view.py (section 6i)
tests/gui_session.py | helper | a dedicated Xvfb session and key injector for the pilot tests
tests/apps/appcfg.py | helper | the reader of the list of apps of the harness
tests/apps/display.py | helper | the display, window and process checks of the harness
tests/apps/ed25519.py | helper | the signer the harness uses to add permissions to a package
tests/apps/pipeline.py | helper | the steps of the harness (download, convert, install, start)
tests/pilot_cycle.py | manual | needs the real Mu app and a dedicated Xvfb; repeats a pilot of saves. Run before every release and before the beta; moves to the weekly run when the apps are built from source (step 13b)
tests/pilot_saves.py | manual | needs the real app and ImageMagick; checks files saved through the GUI. Run before every release and before the beta; moves to the weekly run when the apps are built from source (step 13b)
tests/mu_crash_rate.py | manual | 150 starts of the real Mu app, a measurement of a crash rate. Run before every release and before the beta; moves to the weekly run when the apps are built from source (step 13b)
tests/joplin_fts_probe.py | manual | needs the real Joplin app; a probe of one defect. Run before every release and before the beta; moves to the weekly run when the apps are built from source (step 13b)
tests/kdenlive_clip.py | manual | needs the real Kdenlive app and its output. Run before every release and before the beta; moves to the weekly run when the apps are built from source (step 13b)
tests/menu_refresh.py | manual | needs a GNOME session with a Shell extension, run as the logged-in user. Run at every round on the VMs
tests/power_loss_vm.py | manual | needs a virtual machine that is killed (virsh destroy); docs/POWER-LOSS.md. Run when the code of the store or of the durable writes changes, and before the beta
tests/power_loss_dmlog.py | manual | needs a virtual machine, root and dm-log-writes; docs/POWER-LOSS.md. Run when the code of the store or of the durable writes changes, and before the beta
tests/power_loss_packs.py | manual | makes the packages for the two power-loss tests; run with them (when the store or the durable writes change, and before the beta)
tests/tmp_use.py | manual | a measurement, not a test: the peak of /tmp, /dev/shm and TMPDIR of an app while it works. Run at the next round on the VMs during an export in OpenShot and in Audacity, and with an Electron app in use; the cap of /tmp is 256 MiB
tests/exec_scan.py | manual | a measurement, not a test: which programs an app runs from the folders it writes (the rule behind exec_written). Run before every release and when an app of the harness is added or updated, with the app in use (Joplin writes a 7za in its cache); limit: Chromium makes its processes non-dumpable, so their maps cannot be read
tests/sigfmt.py | helper | the signed message and the signature block of a package, for the tests that make packages by hand
tests/apps/compare.py | helper | compares two runs of the app harness (run.py --json) and refuses when the permissions differ; its unit tests run in test_harness.py

# Test data: origin and license

Every test input in this repository was made for it. No file of a third party
is redistributed (`scripts/check-large-files.sh` keeps the list of tracked files
over 1 MiB empty on purpose). The test data is under the same license as the
code, `MIT OR Apache-2.0`.

| Where | What | Origin |
|---|---|---|
| `conformance/fixtures/` | Valid and invalid `.panpak` files with `expected.json` | Made by `conformance/gen.py`. The signing key is derived from a fixed public seed (a test key, see the top of the script); the files are reproducible byte for byte. |
| `fuzz/corpus/*/seed-*` and the other named files | Seeds of the fuzz targets | Made by `fuzz/gen-seeds.py` or written by hand for a case; they hold synthetic data. |
| `fuzz/corpus/fuzz_manifest/` and `fuzz_index/` (files named by 40 hexadecimal digits) | Inputs that libFuzzer grew from those seeds | Generated by fuzzing our own parsers; they derive only from our seeds. New ones of this kind are ignored by git (`.gitignore`). |
| `panpak-icon/tests/data/` | PNG test icons | Made with Pillow from a generated picture and a flat colour, see the README in that folder. |
| `data/mime/panpak.xml` | The MIME type of `.panpak` files | Ours. |
| `tests/` scripts | Packages, trees and programs built by each test in its own work folder | Made at run time; nothing is downloaded by the tests that run in CI. |
| `tests/apps/apps.example.toml` | The recipes of three programs (source addresses and hashes only) | Ours; the programs are fetched from their own projects when a recipe is built, and are not stored here. |
| `docs/bench-data/` | Results of the benchmarks (CSV, SVG) | Measured by us with `bench/`; the inputs the benchmarks download are pinned by hash and not stored here. |

If you add test data, say here where it comes from. A file taken from another
project needs its license to be compatible and named in this table and in
`THIRD-PARTY-LICENSES`.
